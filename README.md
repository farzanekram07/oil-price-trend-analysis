# Oil Price Trend Analysis

A beginner-to-advanced data analytics project focused on understanding crude oil market behavior using Yahoo Finance data.

---

# Project Goal

The objective of this project is to:

- Understand financial time series data
- Analyze crude oil price trends
- Study volatility and market behavior
- Build analytical thinking using real-world datasets
- Progress toward forecasting and dashboarding

---

# Dataset Source

Data collected using:

- Yahoo Finance API (`yfinance`)
- WTI Crude Oil Futures (`CL=F`)
- Brent Crude Oil Futures (`BZ=F`)
